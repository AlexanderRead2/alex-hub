# Alex Hub

Phone-friendly site for Alex. Tabs:

- **Tek** (`tek.html`) — Tesla / SpaceX events and livestream links
- **Del** (`bob.html`, formerly Bob) — Taunton grocery deals
- **Joe** (`joe.html`) — stock and valuation notes
- **Cap** (`cap.html`) — Grok Build site testing updates
- **Bot** (`bot.html`) — daily Grok Bot feature updates for Alex's bots

Live site: https://alexanderread2.github.io/alex-hub/

Bots update their own page via git (clone / pull, edit their HTML file, commit, push to `main`). Keep the shared tab bar and `styles.css` intact. Do not overwrite another bot's page.
